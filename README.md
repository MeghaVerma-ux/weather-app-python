# Weather App 🌦️

A desktop weather application built using Python, Tkinter, and OpenWeather API.

## Features

* Real-time weather data
* Temperature display
* Humidity display
* Weather condition
* User-friendly GUI

## Technologies Used

* Python
* Tkinter
* Requests API
* OpenWeather API

## How to Run

Install dependencies:

```bash
pip install requests
```

Run the project:

```bash
python weather_app.py
```
